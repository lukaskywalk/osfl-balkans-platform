# Модул 9: Предузетништво и пословне финансије

**ОСФЛ Балканс — Програм финансијске писмености**
**Језичка варијанта:** српски (латиница) · екавски изговор
**Верзија:** 1.0 · март 2026.

**Трајање:** 5–6 сати самосталног учења | 3 x 90-минутне радионице са фацилитатором
**Ниво:** Напредни
**Предуслови:** Основна путања (Модули 1–4) + Модул 6 (Порези) — препоручено

---

## Циљеви учења

Након завршетка овог модула, бићете у стању да:

1. Одаберете одговарајућу пословну структуру за Вашу ситуацију у Србији
2. Успоставите основно пословно рачуноводство и разумете финансијске извештаје
3. Препознате и приступите изворима финансирања (кредити, грантови, инвеститори, ЕУ фондови)
4. Управљате пословним порезима, ПДВ-ом и обавезама усклађености
5. Одвојите личне од пословних финансија и планирате одрживи раст

## 1. Избор пословне структуре

### 1.1 Зашто је структура важна

Пре него што продате први производ или пошаљете прву фактуру, потребна Вам је правна форма. Она одређује:
- Колико пореза плаћате
- Да ли су Ваша лична имовина заштићена у случају пропасти посла
- Колико сложено мора бити Ваше рачуноводство
- Колико сте кредибилни у очима клијената и партнера
- Које могућности финансирања су Вам доступне

### 1.2 Пословне структуре у Србији и региону

#### Предузетник (СЗР)

| Карактеристика | Детаљ |
|---|---|
| **Шта је то** | Ви ЈЕСТЕ посао — нема правног раздвајања између Вас и предузећа |
| **Одговорност** | **Неограничена** — Ваша лична имовина (аутомобил, стан, штедња) је у ризику ако посао пропадне |
| **Трошак оснивања** | Низак (од око 5.000 RSD) |
| **Време оснивања** | 1–5 дана |
| **Рачуноводство** | Једноставно (посебно уз опцију паушалног опорезивања) |
| **Најпогодније за** | Фриленсере, мала услужна предузећа, тестирање пословне идеје |
| **Порез** | Порез на доходак од самосталне делатности на пословни приход (видети Модул 6) |

**Називи у региону:**
- Хрватска: *Обрт* (занатска делатност) или *Слободна дјелатност* (фриленсерска делатност)
- Србија: *Предузетник*
- БиХ: *Обрт* (ФБиХ) / *Предузетник* (РС)
- С. Македонија: *Трговец поединец* (самостални трговац)
- Црна Гора: *Предузетник*
- Албанија: *Персон физик трегтар*

### 1.3 Када прећи са предузетника на d.o.o.

| Сигнал | Зашто је важно |
|---|---|
| Приходи који прелазе праг за паушално опорезивање | Ионако сте приморани на пуно рачуноводство; d.o.o. може бити пореско ефикасније |
| Рад са корпоративним клијентима | Многе компаније преферирају или захтевају уговарање са d.o.o., а не са физичким лицем |
| Преузимање значајног ризика | Неограничена лична одговорност постаје опасна |
| Тражење инвестиција или кредита | Инвеститори улажу у компаније, не у физичка лица |
| Приходи који прелазе 50.000–100.000 EUR/годишње | Могућности пореске оптимизације уз структуру d.o.o. |
| Запошљавање радника | Професионалније и практичније као компанија |
| Више суоснивача | D.o.o. јасно дефинише власништво и одговорности |

## 2. Основе пословног рачуноводства

### 2.1 Зашто је рачуноводство важно

Рачуноводство није само за Пореску управу — оно је начин на који знате да ли Ваше предузеће заиста зарађује, куда одлази Ваш новац и да ли можете приуштити раст.

### 2.2 Три основна финансијска извештаја

**1. Биланс успеха (Рачун добити и губитка)**

Показује да ли је Ваше предузеће профитабилно у одређеном периоду:

```
Приходи (шта сте зарадили)                         5.850.000 RSD
– Трошкови продатих производа (директни трошкови) -1.755.000 RSD
= Бруто добит                                      4.095.000 RSD
– Пословни расходи
    Закуп                           -702.000
    Зараде                        -1.404.000
    Маркетинг                       -351.000
    Софтвер/алати                   -140.400
    Осигурање                       -93.600
    Остало                          -234.000
  Укупни пословни расходи                         -2.925.000 RSD
= Пословни добитак (ЕБИТ)                          1.170.000 RSD
– Порез                                             -175.500 RSD
= Нето добит                                         994.500 RSD
```

**Кључно питање на које одговара:** „Да ли зарађујем?"

**2. Биланс стања**

Преглед онога што предузеће поседује (имовина), дугује (обавезе) и удела власника (капитал) на одређени датум:

```
ИМОВИНА (шта поседујете)            ОБАВЕЗЕ (шта дугујете)
Готовина: 585.000                   Обавезе према добављачима: 351.000
Потраживања: 936.000               Банкарски кредит: 1.170.000
Опрема: 1.404.000                   Пореска обавеза: 210.600
                                    Укупне обавезе: 1.731.600

                                    КАПИТАЛ (удео власника)
                                    Оснивачки капитал: 234.000
                                    Задржана добит: 959.400
                                    Укупни капитал: 1.193.400

Укупна имовина: 2.925.000           Обавезе + Капитал: 2.925.000
```

**Кључно правило:** Имовина = Обавезе + Капитал (увек се изједначава)
**Кључно питање на које одговара:** „Колико вреди предузеће?"

**3. Извештај о новчаном току**

Прати стварни новац који улази и излази — јер добит ≠ готовина:

```
Новац из пословних активности
  Новац примљен од клијената        +5.265.000
  Новац плаћен добављачима          -1.404.000
  Новац плаћен за расходе            -2.574.000
  Плаћени порез                        -175.500
  Нето пословни новчани ток                         +1.111.500

Новац из инвестиционих активности
  Куповина опреме                      -585.000
  Нето инвестициони новчани ток                       -585.000

Новац из финансијских активности
  Примљени банкарски кредит          +1.170.000
  Отплата кредита                       -234.000
  Нето финансијски новчани ток                       +936.000

Нето промена готовине                              +1.462.500
Почетна готовина                                     292.500
Крајња готовина                                   1.755.000
```

**Кључно питање на које одговара:** „Имам ли довољно готовине за плаћање рачуна?"

### 2.3 Добит вс. готовина — критична разлика

Многа предузећа пропадају не зато што нису профитабилна, већ зато што остану без готовине. То се дешава када:

- Фактуришете клијенту 585.000 RSD (добит је евидентирана!) али плати тек за 60 дана (нема готовине још)
- Морате платити добављачима, кирију и зараде САДА, пре него што пристигну уплате клијената
- Улажете у залихе или опрему (готовина излази) пре него што остварите приход (готовина улази)

**Ово се назива „јаз у новчаном току" и уништава више малих предузећа него недостатак потражње.**

**Решење:** Увек пратите новчани ток одвојено од добити. Имајте резерву (пословни фонд за хитне случајеве) од најмање 2–3 месеца пословних трошкова.

### 2.4 Основне рачуноводствене праксе

| Пракса | Зашто је важна |
|---|---|
| **Одвојени банковни рачуни** | Лични и пословни новац на различитим рачунима — увек |
| **Одмах фактуришите** | Не одлажите фактурисање — то одлаже и наплату |
| **Пратите сваки трошак** | Чувајте сваки рачун (дигитални је у реду). Неприказани трошкови = преплаћени порез |
| **Користите рачуноводствени софтвер** | Чак и једноставна табела је боља од кутије пуну рачуна. Размотрите: ФрееАгент, Wаве (бесплатно) или локална решења |
| **Усклађујте месечно** | Упоређујте извод рачуна са Вашим евиденцијама сваког месеца |
| **Одвајајте новац за порез** | Правило 30% из Модула 6 важи и за предузећа |
| **Ангажујте рачуновођу** | За d.o.o. компаније, професионално рачуноводство је практично обавезно. Цена: 12.000–35.000 RSD/месечно |

## 3. Финансирање Вашег предузећа

### 3.1 Преглед извора финансирања

| Извор | Опсег износа | Цена | Брзина | Најпогодније за |
|---|---|---|---|---|
| **Лична штедња (сопствено финансирање)** | Било који | Бесплатно (али високи опортунитетни трошак) | Одмах | Тестирање идеја, рана фаза |
| **Пријатељи и породица** | Мали–средњи | Низак/нема (али ризик за односе) | Брзо | Почетна средства, поверење |
| **Банкарски кредит** | 585.000–58.500.000+ RSD | 4–10% камате | 2–8 недеља | Етаблирана предузећа са приходом |
| **Микрозајам** | 58.500–2.925.000 RSD | 5–15% камате | 1–4 недеље | Стартапи, мала предузећа, мање документације |
| **Државни грантови** | 117.000–5.850.000+ RSD | Бесплатно (бесповратно) | 1–6 месеци (поступак пријаве) | Специфични сектори, демографске групе, региони |
| **ЕУ фондови (ИПА, Хоризонт итд.)** | 1.170.000–117.000.000+ RSD | Бесплатно (бесповратно, али сложена пријава) | 3–12 месеци | Иновације, прекогранични пројекти, истраживање |
| **Анђео инвеститор** | 1.170.000–23.400.000 RSD | Капитал (уступате проценат власништва) | 1–6 месеци | Скалабилни стартапи, технолошка предузећа |
| **Ризични капитал (ВЦ)** | 23.400.000–585.000.000+ RSD | Капитал + контрола над управом | 3–12 месеци | Стартапи са високим растом и доказаним резултатима |
| **Групно финансирање (цроwдфундинг)** | 117.000–11.700.000+ RSD | Накнада платформе (~5–10%) | 1–3 месеца кампање | Потрошачки производи, креативни пројекти, друштвени утицај |

### 3.2 Банкарски кредити за мала предузећа

**Шта банке траже:**
1. **Пословни план** — Јасан опис онога што радите, анализа тржишта, пројекције прихода
2. **Финансијски извештаји** — Најмање 1–2 године историје (за постојећа предузећа)
3. **Средство обезбеђења** — Некретнина, опрема или лично јемство
4. **Новчани ток** — Можете ли отплатити кредит из пословног прихода?
5. **Ризик сектора** — Банке су опрезне у одређеним областима (угоститељство, стартапи)
6. **Кредитна историја власника** — Ваша лична кредитна способност је важна (Модул 3)

**Уобичајени кредитни производи за мала предузећа:**

| Производ | Типична намена | Типични услови |
|---|---|---|
| **Кредит за обртна средства** | Покривање краткорочних јаза у новчаном току | 1–3 године, обезбеђен потраживањима |
| **Инвестициони кредит** | Опрема, реконструкција, проширење | 3–10 година, обезбеђен имовином |
| **Прекорачење по текућем рачуну** | Свакодневно управљање готовином | Револвинг, обнавља се годишње |
| **Кредити уз ЕУ гаранције** | Субвенционисани кредити уз гаранције ЕИФ/ЕИБ (доступни у свим балканским земљама) | Ниже стопе, мање обезбеђење |

### 3.3 Грантови и државна подршка

Свака балканска земља нуди грантове за специфичне пословне активности. Кључни програми:

**Хрватска:**
- ХАМАГ-БИЦРО грантови за иновације и МСП
- ЕУ структурни фондови (као чланица ЕУ — највећи фонд у региону)
- Субвенције за самозапошљавање Хрватског завода за запошљавање (ХЗЗ)
- Грантови Министарства господарства за дигитализацију, зелену транзицију

**Србија:**
- Инноватион Фунд (Фонд за иновациону делатност) — пратећи грантови за технологију/иновације
- Развојна агенција Србије (РАС) — грантови за стартапе и МСП
- Грантови локалне самоуправе (варирају по општини)
- Програми које подржавају УСАИД и Светска банка

**БиХ:**
- Развојне агенције на нивоу ентитета (ФИПА, фондови на нивоу ентитета)
- Ограничени, али растући ЕУ ИПА фондови
- Кантонални грантови (ФБиХ)

**С. Македонија:**
- Фонд за иновације и технолошки развој (ФИТД) — грантови и суфинансирање
- Грантови за самозапошљавање кроз Агенцију за запошљавање
- Програми ЕУ ИПА прекограничне сарадње

**Црна Гора:**
- Инвестиционо-развојни фонд (ИРФ) — субвенционисани кредити и грантови
- Програми самозапошљавања Завода за запошљавање
- ЕУ ИПА програми

**Албанија:**
- Албанска агенција за инвестиције и развој (АИДА)
- ИПАРД фондови за пољопривреду и рурални развој
- Програми које подржавају Светска банка и ЕБРД
- Грантови за развој предузетништва кроз међународне донаторе

### 3.4 Писање основног пословног плана

Пословни план није само за инвеститоре или банке — он Вас приморава да систематски промислите своју идеју. Једноставан, ефикасан план покрива:

| Секција | Кључна питања | Дужина |
|---|---|---|
| **Сажетак** | Чиме се бавите? Који проблем решавате? Шта Вам треба? | 1 страница |
| **Производ/услуга** | Шта тачно продајете? Чиме се разликујете? | 1–2 странице |
| **Тржиште** | Ко су Ваши купци? Колико је тржиште велико? Ко су Ваши конкуренти? | 1–2 странице |
| **Маркетинг и продаја** | Како ће Вас купци пронаћи? Како ћете продавати? Цене? | 1–2 странице |
| **Операције** | Како испоручујете? Шта Вам треба (људи, опрема, простор)? | 1 страница |
| **Финансијске пројекције** | Приходи, расходи, добит, новчани ток за 1–3 године | 1–2 странице |
| **Захтев за финансирањем** | Колико Вам треба? За шта ћете то употребити? Како ћете отплатити? | 1 страница |

**Укупно: 7–11 страница** — то је све што је потребно за план малог предузећа. Немојте претерано компликовати.

### 3.5 Шаблон једностраничног пословног плана — практични приказ

За већину микропредеузећа у Србији, не треба Вам план од 10 страница за почетак. Јасан, искрен једностраничан план приморава Вас да одговорите на тешка питања пре него што потрошите новац. У наставку је шаблон са осам секција, праћен разрађеним примером.

**Шаблон:**

| # | Секција | Шта писати |
|---|---|---|
| 1 | **Пословна идеја** | Шта продајете или радите? Опишите у 2–3 реченице. |
| 2 | **Циљна група** | Ко то купује? Будите конкретни: старост, локација, ниво прихода, навике. Колико потенцијалних купаца је у Вашем домету? |
| 3 | **Конкуренција** | Ко још то ради у Вашој области? Наведите 2–3 конкурента. Шта ћете радити боље, јефтиније или другачије? |
| 4 | **Модел прихода** | Како зарађујете? Шта наплаћујете? По комаду, по сату, претплатом, провизијом? Која је Ваша просечна вредност трансакције? |

| 6 | **Месечни пословни трошкови** | Сви редовни трошкови: кирија, репроматеријал, зараде, комуналије, отплате кредита, рачуноводство, маркетинг. |

**Кључне ПДВ обавезе:**
1. Региструјте се за ПДВ када Ваш годишњи приход прекорачи праг (нека предузећа се могу регистровати добровољно испод прага)
2. Наплаћујте ПДВ на Вашим фактурама
3. Подносите ПДВ пријаве (месечно или квартално, зависно од земље)
4. Плаћајте разлику између ПДВ-а који сте наплатили и ПДВ-а који сте платили на пословне трошкове
5. Чувајте евиденцију 5–10 година (варира по земљи)

### 4.2.1 Регистрација за ПДВ — корак по корак

**Корак 1: Знате Ваш праг.**

Регистрација за ПДВ постаје обавезна када Ваш годишњи приход (не добит) премаши праг који је специфичан за сваку земљу:

| Земља | Праг | Оквирни еквивалент у EUR |
|---|---|---|
| Хрватска | 40.000 EUR | 40.000 EUR |
| Србија | 8.000.000 RSD | ~68.000 EUR |
| БиХ | 50.000 BAM | ~25.500 EUR |
| С. Македонија | 2.000.000 MKD | ~32.500 EUR |
| Црна Гора | 30.000 EUR | 30.000 EUR |
| Албанија | 10.000.000 ALL | ~95.000 EUR |

Морате пратити Ваш приход за последњих 12 месеци. Када пређете праг, обавезни сте да се региструјете — обично у року од 15 дана у већини земаља. Немојте чекати до краја године да проверите.

**Корак 2: Региструјте се код пореског органа.**

Поступак је сличан у целом региону: поднесите захтев Пореској управи (е-Порезна у Хрватској, Пореска управа у Србији, Уино у БиХ итд.) уз регистрационе документе предузећа, финансијске евиденције које показују да сте прешли праг и попуњен образац за ПДВ регистрацију. Обрада траје 5–15 радних дана. Добијате ПДВ број који мора бити наведен на свим фактурама.

**Корак 3: Разумејте шта се мења када постанете обвезник ПДВ-а.**

- **Морате наплаћивати ПДВ на свим фактурама.** Ваше цене се ефективно повећавају за износ ПДВ-а (или Ви апсорбујеште трошкове, смањујући маржу). За предузећа оријентисана на крајње потрошаче (кафане, продавнице), то често значи подизање цена.
- **Подносите ПДВ пријаве** — месечно у већини земаља, квартално у некима (Хрватска дозвољава кварталне за мања предузећа). Свака пријава израчунава: наплаћени ПДВ од купаца минус ПДВ плаћен на пословне набавке (улазни ПДВ). Разлику уплаћујете Пореској управи.
- **Можете одбити улазни ПДВ.** Сваки пословни расход на који сте платили ПДВ (репроматеријал, опрема, услуге) смањује Ваш ПДВ рачун. Ово је главна предност — повраћате ПДВ на трошкове.
- **Ваше рачуноводство постаје сложеније.** Морате пратити ПДВ на свакој трансакцији, и при продаји и при набавци.

**Честа грешка: касна регистрација.**

Ако пређете праг и пропустите рок за регистрацију, дуговани ПДВ на све продаје од датума када сте требали да се региструјете пада на Вас — али сте већ наплаћивали клијентима без ПДВ-а, па ПДВ плаћате из сопственог џепа. Казне се крећу од 58.500 до 1.170.000 RSD, зависно од земље и трајања неусклађености. У Србији, понављана кршења могу довести до привременог затварања предузећа.

**Добровољна регистрација: када има смисла.**

Можете се регистровати за ПДВ и испод прага. Ово је повољно ако:
- **Већина Ваших клијената су обвезници ПДВ-а (Б2Б):** Они могу одбити Ваш ПДВ, па им Ваша цена није важна — али сада Ви можете одбити ПДВ на Ваше расходе.
- **Имате високе трошкове покретања:** Велике набавке опреме или реновација значе значајан улазни ПДВ који можете повратити.
- **Желите да делујете професионалније:** Неки корпоративни клијенти преферирају добављаче који су обвезници ПДВ-а.

Ако су Ваши клијенти углавном потрошачи (Б2Ц), добровољна регистрација обично штети — морате наплаћивати више или прихватити нижу маржу, а потрошачи не могу повратити ПДВ.

## Студије случаја

### Студија случаја 1: Филипов прелаз са предузетника на d.o.o. (Београд)

Филип, 30, веб девелопер из Београда, почео је да ради као фреиленсер као предузетник са паушалним опорезивањем са 25 година. До треће године, његови приходи су достигли око 8.190.000 RSD/годишње (~70.000 EUR) — далеко изнад прага за паушално опорезивање.

**Матрица одлучивања:**

| Фактор | Остати предузетник (пуно рачуноводство) | Прећи на d.o.o. |
|---|---|---|
| Пореска структура | Порез на доходак на добит | Порез на добит 15% + порез на дивиденду при исплати |
| Одговорност | Неограничена лична | Ограничена на капитал компаније |
| Трошак рачуноводства | ~12.000 RSD/месечно | ~25.000 RSD/месечно |
| Кредибилност код клијената | Неки велики клијенти преферирају d.o.o. | Већа перципирана професионалност |
| Будуће инвестиције | Инвеститори не улажу у предузетнике | Може примити инвестиције, додати партнере |

**Филипово поређење ефективног пореза (на 8.190.000 RSD добити):**
- Предузетник: ~2.700.000 RSD укупан порез + доприноси (~33%)
- D.o.o.: ~1.228.500 RSD порез на добит + ~736.650 RSD порез на дивиденду (ако би повукао сву добит) = ~1.965.150 RSD (~24%)
- **Уштеда: ~734.850 RSD/годишње преласком на d.o.o.**

Оsim тога, могао би оставити добит у компанији (реинвестирати) и не плаћати порез на дивиденду док је не повуче.

**Поступак:** Регистрација је трајала 7 дана и коштала је око 47.000 RSD (нотар, АПР портал, минимални капитал од 100 RSD). Књиговодство је водио рачуновођа.

**Поука:** Паушални предузетник је савршен за почетак, али постоји ниво прихода на ком прелазак на d.o.o. доноси значајну уштеду и смањује лични ризик.

### Студија случаја 2: Јеленина криза новчаног тока (Нови Сад)

Јелена, 38, водила је малу агенцију за графички дизајн у Новом Саду (d.o.o.) са 3 запослена. Приходи: 14.040.000 RSD/годишње (~120.000 EUR). На папиру профитабилна.

**Криза:** У септембру, њена два највећа клијента (који су чинили 60% прихода) оба су одложила плаћање за 90 дана. У међувремену, морала је да плати:
- Зараде: 526.500 RSD/месечно (3 запослена)
- Закуп канцеларије: 93.600 RSD/месечно
- Доприноси за социјално осигурање: ~234.000 RSD/месечно
- Добављачи: 140.400 RSD/месечно
- **Месечно „сагоревање": ~994.500 RSD**

Са 702.000 RSD на пословном рачуну и више од 1.638.000 RSD у неплаћеним фактурама, била је неколико недеља од немогућности исплате зарада.

**Хитне мере:**
1. Позвала оба клијента — преговарала о делимичним исплатама (један је одмах платио 50%)
2. Обратила се банци за хитно прекорачење — одобрено на основу потраживања (585.000 RSD)
3. Одложила сопствену зараду за један месец
4. Смањила неопходне трошкове (маркетиншке претплате, залихе канцеларијског материјала)

**Дугорочна решења:**
1. Увела рокове плаћања од 30 дана са каматом од 5% за кашњење (уместо неформалног „плати кад стигнеш")
2. Захтевала аванс од 30% на свим пројектима изнад 351.000 RSD (~3.000 EUR)
3. Изградила пословни фонд за хитне случајеве од 3 месеца (2.983.500 RSD) у току наредне године
4. Диверсификовала базу клијената — ниједан клијент сада не премашује 25% прихода

**Поука:** Приход није готовина. Профитабилно предузеће може пропасти због кризе новчаног тока. Примените рокове плаћања, захтевајте авансе и одржавајте пословни фонд за хитне случајеве.

### Студија случаја 3: Марково путовање кроз грантове (Ниш)

Марко, 28, хтео је да отвори малу печеницу-специјалитет кафу у Нишу. Имао је 351.000 RSD (~3.000 EUR) уштедина — довољно за део опреме, али не за комплетан старт.

**План:**
- Укупни трошкови покретања: 2.340.000 RSD (~20.000 EUR)
- Његова штедња: 351.000 RSD
- Јаз: 1.989.000 RSD

**Мешавина финансирања:**
1. **РАС грант** (Развојна агенција Србије) — Пријавио се за стартер грант за МСП. После 3 месеца, добио је 585.000 RSD (~5.000 EUR) као бесповратну средство.
2. **Микрозајам** — Узео микрозајам од 819.000 RSD од лиценциране микрофинансијске институције уз 8% камате на 3 године (~27.000 RSD/месечно отплате).
3. **Породични зајам** — Позајмио 234.000 RSD од стрица (писани споразум, враћен у року од 12 месеци, без камате).
4. **Лична штедња** — 351.000 RSD

**Укупно: 1.989.000 RSD прикупљено** да се покрије јаз.

**Шта је осигурало успех пријаве за грант:**
- Јасан пословни план (10 страница, користећи шаблон из одељка 3.4)
- Истраживање тржишта које показује да нема специјализоване печенице у радијусу од 5 км
- Отварање радних места: планира запошљавање 2 радника у року од 6 месеци
- Обавеза локалног набављања (куповина од локалних добављача)
- Реалне финансијске пројекције (тачка покрића у 8. месецу)

**Резултат после годину дана:** Печеница је постала профитабилна у 10. месецу (два месеца касније него што је пројектовано). Марко је запослио 3 особе (једну више од плана). Сада истражује грант Инноватион Фунд-а за проширење.

**Поука:** Немојте покушавати да финансирате све из једног извора. Креативна мешавина грантова, микрозајмова, породичне подршке и личне штедње може учинити посао могућим. Грантови захтевају труд за пријаву, али су бесплатни новац — увек вреди покушати.

## Речник кључних појмова

| Појам | Дефиниција |
|---|---|
| **Биланс стања** | Финансијски извештај који приказује имовину, обавезе и капитал у одређеном тренутку |
| **Сопствено финансирање (боотстрапpinг)** | Покретање предузећа сопственим средствима без спољног финансирања |
| **Новчани ток** | Кретање новца који улази и излази из предузећа |
| **Јаз у новчаном току** | Период када расходи морају бити плаћени пре него што се наплати приход |
| **Порез на добит предузећа** | Порез на профит компаније |
| **D.o.o.** | Друштво са ограниченом одговорношћу — најчешћа пословна форма на Балкану |
| **Двојно књижење** | Рачуноводствени систем у коме се свака трансакција евидентира на два рачуна (дугује и потражује) |
| **Капитал** | Удео власника у предузећу (имовина минус обавезе) |
| **Фискализација** | Електронско извештавање фактура у реалном времену Пореској управи |
| **Бруто добит** | Приход минус трошкови продатих производа (пре пословних расхода) |
| **Биланс успеха (П&Л, Рачун добити и губитка)** | Финансијски извештај који приказује приходе, расходе и добит за одређени период |
| **Микрозајам** | Мали зајам (обично до 25.000 EUR) за мала предузећа, често са једноставнијим захтевима |
| **Нето добит** | Приход минус сви расходи и порези — „последња линија" |
| **Предузетник / СЗР** | Самостална радња — пословна форма у којој је физичко лице = предузеће |
| **Пословни расходи** | Редовни трошкови пословања (закуп, зараде, комуналије, маркетинг) |
| **Приход** | Укупни приход од продаје роба или услуга |
| **Самостални предузетник** | Физичко лице које послује без одвојеног правног субјекта |
| **ПДВ (Порез на додату вредност)** | Порез који се наплаћује на пословне продаје изнад прага за регистрацију |
| **Обртни капитал** | Готовина доступна за свакодневно пословање (обртна имовина минус краткорочне обавезе) |
